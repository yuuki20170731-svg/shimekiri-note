# Reactをブラウザで描画する構成

2026-09-28。合意したReact・TypeScript、Supabase、メール・プッシュの機能を維持する。

最初はSitesのVinextスターターで画面を描画したが、Windowsで初回起動が長く、複数の描画用Reactの組み合わせで操作不能になる問題を実機確認で発見した。このアプリは非公開の個人情報をログイン後に読むため、サーバーでの事前描画を必要としない。

ブラウザ側のReactとViteで画面を描画し、保存と認証はSupabase、定期通知はSupabaseのサーバー処理に任せる。Sitesへは静的な公開用ファイルを出力できる。利用者の情報をブラウザだけで永続化する構成へ変更したものではない。データベースの所有者制限でアクセスを保護する。

公開時の設定はビルドに含まれる。公開用キーを変える場合は再ビルドが必要。管理用キーやメール配信の秘密は画面のビルドへ含めない。
