# 検証結果（2026年9月30日）

## 確認できたこと

- 自動テスト41件、TypeScriptの型チェック、ESLint、書式確認、公開用ビルドが成功しました。
- 公開デモで架空メールの会社名、締切日、時刻、提出内容、提出先の候補表示を確認しました。
- 一覧の次の締切カードと作品紹介ページをPCで表示し、スマホ幅390pxでも横にはみ出さないことを確認しました。
- PCの実アカウントで締切の保存・編集・再読み込み後の保持を確認しました。
- Gmailの一覧と検索が動作しました。Androidでは利用者が選んだ実メールから企業名・締切日・時刻を読み取り、元の案内と一致することを利用者が確認しました。メールの本文は保存していません。
- Gmailの一覧から本文プレビューを除き、件名・差出人・日付のみを表示します。本文は利用者がメールを選んだときに取得します。
- Jev用の日付候補の最小化、未認証リクエストの拒否、低確信度の候補を採用しない処理を自動テストで確認しました。実モデルへの試験リクエストはCloudflare AI Gatewayのクレジット不足（2021）で拒否されたため、無料版では無効にしました。
- 公開用ZIPに開発ツールの設定や秘密鍵が含まれないことを確認しました。

## 残る確認

- 同じアカウントでAndroidとPCの締切情報が同期すること。
- AndroidへのWebプッシュと締切通知メールが実際に届くこと。通知メールの接続はBrevoのキー不一致で止まっています。
- 新しい利用者の登録確認メールが届き、アカウントを有効化できること。
- Gmail連携を一般利用者に提供するには、Googleによる権限の確認が必要です。現時点では登録済みテスト利用者だけが接続できます。

読み取り候補は保存前に元の案内と照合してください。特に年や時刻が不明なメールをアプリだけで確定しません。
