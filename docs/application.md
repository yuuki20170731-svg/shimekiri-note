# 応募フォーム用テキスト

## 概要

締切ノートは、就職活動の案内メールから企業名・提出物・締切・提出先の候補を読み取り、確認して一覧に残せるWebアプリです。スマホで案内を受け取り、PCで提出する就活生を想定。締切が近い順に見返せるほか、架空データを使ったデモをログインなしで試せます。

## 開発内容・工夫した点（290文字）

就活中、企業から前日に届いた連絡で締切を思い出し、過去の案内メールを探し直す負担から制作しました。2026年9月28日〜30日の3日間、企画・UI設計・React/TypeScriptでの実装・テストを個人で担当。メールの書式が企業ごとに異なるため、日付・時刻・提出物の候補を端末内で抽出し、複数候補や時刻不明を勝手に確定しない設計にしました。Androidで「候補が見えない」「文字が薄い」という実際の操作上の問題を確認し、結果への移動と配色を改善。Supabaseの行レベル権限、通知予約の変更・停止も実装し、41件の自動テストで検証しました。公開デモは架空データで試せます。
